## 1. Guideline 2.3.6 — возрастной рейтинг. ЗАКРЫТО

В анкете возрастного рейтинга стояло **Age Assurance = да**, то есть
приложение заявляло о механизме проверки возраста. Такого механизма в нём
нет — Apple его искала и не нашла.

Исправлено через API 06.09.2026: `ageAssurance: false`, `parentalControls:
false`. Ничего в приложении менять не пришлось — врала анкета, а не код.

## 2. Guideline 5.1.1(v) — обязательный пол. ЗАКРЫТО правкой в коде

Регистрация не пускала дальше без выбора пола (`if (gender == null) return
'Выберите пол'`). Apple права: требовать можно только те данные, без которых
приложение не работает.

Пол использовался ровно для окончаний в поздравлениях и на бланке диплома
(«прошёл» / «прошла»). Теперь он необязателен:

- поле подписано «Пол (необязательно)», повторное нажатие снимает выбор;
- в хранилище пустое значение — не выдуманный мужской, как раньше;
- на сервер поле не уходит вовсе, если не заполнено;
- в профиле строка про пол просто не показывается;
- если пол не указан, тексты пишутся в мужском роде — как принято
  в русском языке при неизвестном адресате.

Покрыто тестами (`test/optional_gender_test.dart`): регистрация без пола
проходит, указанный пол сохраняется, старые записи читаются как «не указан»,
остальные проверки анкеты на месте.

**Требует новой сборки — 1.0.0 (4).** Номер 3 занят и просрочен.

## 3. Guideline 2.1 — платное содержимое. ЗАКРЫТО: наград в магазине больше нет

Во всём приложении цен не было нигде — ни в курсах, ни в уроках, ни на
сервере (`courses.json` полей цены не содержит вовсе). Деньги упоминались
ровно в одном месте: награда «скидка 1000 сом при оплате курса у устаза».
Она и вызвала вопрос — раз есть скидка, значит есть плата.

По решению владельца награды из магазина убраны. Экран остался: баланс
коинов виден, прошлые выкупы видны, коины продолжают начисляться за намазы.
Вместо списка наград — прямая строка «награды скоро появятся».

Вернуть их можно одной строкой в `shopItems`; прежние опознаватели на
сервере сохранены, закомментированный список лежит рядом.
