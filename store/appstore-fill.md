# Раздел «Информация о приложении»

## Авторские права

Год плюс правообладатель. Значок © НЕ ставить — App Store добавит сам.
Ссылок в поле быть не должно.

```
2026 ИП Өмөрали уулу Нурзаман
```

Правообладателем указан ИП: аккаунт разработчика оформлен на него, и он же
назван держателем данных в политике конфиденциальности. Если приложение
считает своим организация «Ирфан» — указывать надо её, но тогда имя
правообладателя разойдётся с именем аккаунта, и ревьюер может уточнить.

## Права на контент

Ответ честный — **да, приложение содержит чужой контент**:

- смысловой перевод Корана и тафсир Azan.ru — 6236 аятов и 4267 групп
  толкований лежат в сборке офлайн (`assets/quran/`);
- аудио чтецов — стримится с `cdn.islamic.network`, в сборке файлов нет.

⚠️ Отмечая «да», вы подтверждаете Apple наличие прав. На 03.09.2026 письма
от организации «Ирфан» и от Azan.ru существуют только как ЗАГОТОВКИ в
`store/rights/` — разрешение Azan.ru устное, подписанного нет. Apple такие
подтверждения заранее не проверяет, вопрос возникает только по жалобе
правообладателя, а источник у вас подписан на каждом листе тафсира. Но
решение — ваше; текст письма готов и ждёт отправки.

## Файл с данными о зоне покрытия (для приложения маршрутизации)

Оставить пустым. Поле для навигаторов, строящих маршруты с пошаговыми
подсказками. Компас киблы маршрутизацией не считается — он показывает
направление, а не ведёт по дороге.

# Пять пунктов, которые App Store Connect требует перед отправкой

## 1. Основная категория

«Информация о приложении» → Категория:

- Основная: **Справочники**
- Дополнительная: **Образование**

## 2. Ценообразование

Раздел «Ценообразование и доступность»:

- Цена: **Бесплатно** (ценовой ярус 0)
- Доступность: все страны и регионы. Ограничивать незачем — приложение
  бесплатное, а кыргызская диаспора живёт не только в КР.

## 3. Сборка

На странице версии, блок «Сборка» → выбрать **1.0.0 (1)**. Если её там нет,
значит Apple ещё обрабатывает — подождите и обновите страницу.

## 4. URL политики конфиденциальности

Раздел «Конфиденциальность приложения», поле вверху:

```
https://irfan.kg/privacy.html
```

## 5. Анкета App Privacy — по шагам

Там же, кнопка «Начать» / «Изменить». Порядок вопросов:

**Собираете ли вы данные от этого приложения?** → **Да**

Дальше отметить восемь типов данных. Для КАЖДОГО Apple спросит одно и то же:
цель сбора, связаны ли данные с личностью, используются ли для отслеживания.

| Категория → тип | Цель | С личностью | Отслеживание |
|---|---|---|---|
| Контактные данные → Имя | Функциональность приложения | **да** | нет |
| Контактные данные → Номер телефона | Функциональность приложения | **да** | нет |
| Геопозиция → Грубая геопозиция | Функциональность приложения | **да** | нет |
| Пользовательский контент → Другой пользовательский контент | Функциональность приложения | **да** | нет |
| Идентификаторы → ID устройства | Функциональность приложения | **да** | нет |
| Данные об использовании → Взаимодействие с продуктом | Функциональность приложения | **да** | нет |
| Диагностика → Данные о сбоях | Функциональность приложения | **НЕТ** | нет |
| Другие данные | Функциональность приложения | **да** | нет |

Пояснения, если засомневаетесь при заполнении:

- **Грубая геопозиция** — на сервер уходит только НАЗВАНИЕ города в профиле.
  Координаты не отправляются никогда, время намаза считается на телефоне.
- **Другой пользовательский контент** — сообщения в чате эфира, заметки и
  закладки в резервной копии, личные обеты.
- **ID устройства** — ключ из Keychain, которым сервер отличает владельца
  записи от постороннего, знающего номер. Сюда же относится токен APNs.
- **Данные о сбоях** — единственный тип НЕ связанный с личностью: в отчёте
  о падении уходят текст ошибки, стек и версия ОС, телефона в нём нет.
- **Другие данные** — пол и возраст из анкеты регистрации.

Чего в приложении НЕТ и отмечать не надо: почта, платёжные данные, адрес,
контакты, фотографии (выбранные обои остаются на телефоне), точная
геопозиция, поиск, реклама, здоровье, финансы.

**Отслеживание: нет.** Рекламных SDK и сторонней аналитики в сборке нет,
`NSPrivacyTracking` = false. Экран про App Tracking Transparency не появится.

Анкета должна совпадать с `ios/Runner/PrivacyInfo.xcprivacy` — Apple сверяет
одно с другим, расхождение это повод для отказа. Сверено 29.08.2026.
