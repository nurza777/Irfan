```

УРОКИ И ЭФИРЫ
```

## Анкета App Privacy — готовые ответы

Заполнено по факту: проверено, что именно приложение отправляет на сервер.
Совпадает с `ios/Runner/PrivacyInfo.xcprivacy` — Apple сверяет одно с другим.

**Опубликовано в App Store Connect 15.09.2026** — до этого там по ошибке стояло «данные не собираются», а сборка 1.0.1 уже заявляла сбор.

**Tracking: No.** Рекламных SDK и сторонней аналитики в сборке нет,
`NSPrivacyTracking` = false, `NSPrivacyTrackingDomains` пуст.

| Категория → тип | Связано с личностью | Назначение | Что это на самом деле |
|---|---|---|---|
| Contact Info → Name | да | App Functionality | имя в профиле, подписывает сообщения в чате и сертификаты |
| Contact Info → Phone Number | да | App Functionality | опознаватель аккаунта, по нему устаз выдаёт доступ к курсам |
| Location → Coarse Location | да | App Functionality | **только название города** в профиле; координаты на сервер не уходят — расчёт времени намаза целиком на телефоне |
| User Content → Other User Content | да | App Functionality | сообщения в чате эфира, заметки и закладки в резервной копии, личные обеты |
| User Content → Customer Support | да | App Functionality | переписка с поддержкой в приложении (с 1.0.1) |
| Identifiers → Device ID | да | App Functionality | ключ устройства из Keychain: им сервер отличает владельца записи от постороннего, знающего номер |
| Usage Data → Product Interaction | да | App Functionality | счётчики прочитанных намазов, серия дней, коины |
| Diagnostics → Crash Data | **нет** | App Functionality | `POST /crash`: текст ошибки, стек, версия, версия ОС. Номера телефона в теле нет — поэтому «не связано с личностью» |
| Other Data | да | App Functionality | пол, возраст и дата рождения из анкеты регистрации |

Чего в приложении **нет** и что отмечать не надо: почта, платёжные данные,
адрес, контакты, фотографии (выбранные обои остаются на телефоне и никуда
не отправляются), точная геопозиция, поиск, реклама, здоровье, финансы.

### Одно место, где нужно ваше решение

Apple относит к «Sensitive Info» в том числе данные о религиозных
убеждениях. Трекер намазов — это запись религиозной практики, и она хранится
на сервере, а устаз её видит.

**Рекомендую не отмечать «Sensitive Info»** и оставить как есть: категория
приложения и так религиозная, сам по себе факт пользования им Apple
сенситивными данными не считает, а тысячи исламских и христианских
приложений эту графу не отмечают. Но решение ваше — если отметите, ревью
пройдёт тем более спокойно, зато карточка в App Store получит заметную
строку про чувствительные данные.

## Возрастной рейтинг — готовые ответы

Итог: **4+**, но только при честном ответе про пользовательский контент.

| Вопрос анкеты | Ответ |
|---|---|
| Насилие мультяшное / реалистичное | Нет |
| Сексуальный контент, нагота, откровенные темы | Нет |
| Ненормативная лексика, грубый юмор | Нет |
| Алкоголь, табак, наркотики | Нет |
| Страх, ужасы | Нет |
| Медицинская информация | Нет |
| Азартные игры, конкурсы | Нет |
| Неограниченный доступ в интернет | Нет — встроенного браузера нет, внешние ссылки открываются в Safari |
| **Пользовательский контент / общение между пользователями** | **Да — чат прямого эфира** |

К вопросу про пользовательский контент Apple требует показать средства
модерации. Они в приложении есть, и это стоит перечислить в том же поле:
фильтр грубой лексики на сервере, жалоба на любое сообщение (долгое нажатие),
скрытие автора читателем, удаление аккаунта.

Если ответить «нет» про чат — рейтинг придётся переподавать после первой же
жалобы, а это новый цикл ревью.
