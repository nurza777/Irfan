## Описание

```
«Ирфан» — приложение для ежедневной практики: время намаза, трекер молитв,
Коран с переводом и уроки преподавателей.

ВРЕМЯ НАМАЗА
Точное время для вашего города — по геолокации или выбором из списка.
Напоминание приходит вовремя или за 5–30 минут, отдельно по каждому намазу.
Виджет на экране «Домой» показывает ближайший намаз.

ТРЕКЕР МОЛИТВ
Отмечайте прочитанные намазы, следите за серией дней подряд и статистикой
за любой период — за неделю, месяц или всё время.

КОРАН
Полный текст с подсветкой правил таджвида и пояснениями. Девять переводов
на выбор, включая транслитерацию кириллицей. Десять чтецов, аудио можно
скачать и слушать без интернета. Закладки, заметки и режим мусхафа —
страница выглядит как в бумажной книге.

ЗИКРЫ И АЗКАРЫ
Счётчик зикров с целями на день, азкары утра и вечера, после намаза и
поминание — с арабским текстом, транслитерацией и смыслом. Личные обеты
с напоминаниями в удобное время.

99 ИМЁН АЛЛАХА
Листаемые карточки с озвучкой и значением каждого имени, а также викторина
для проверки себя.

УРОКИ И ЭФИРЫ
Курсы преподавателей с видеоуроками и удобным плеером: перемотка, скорость,
продолжение с места остановки. Прямые эфиры с чатом.

ЕЩЁ
• Компас киблы
• Режим Рамадана: сухур, ифтар и обратный отсчёт
• Коины за прочитанные намазы и зикры — обмениваются на награды у преподавателя
• Полностью на кыргызском и русском
• Своё фото как фон приложения

Приложение бесплатное, без рекламы и без слежки.
```

## Заметка для App Review (App Review Information → Notes)

Английский — ревьюеры читают на нём.

```
The app is free, has no ads and no in-app purchases.

HOW TO SIGN IN
Accounts are created inside the app. Please tap the person icon in the top-left corner of the home
screen ("Аккаунт"), switch to the "Регистрация" tab and register with:

  phone: ⟨НОМЕР_ДЛЯ_РЕВЬЮ⟩
  name:  any
  password: any (min 6 characters)

We have pre-granted this phone number full access to the course catalogue,
so the "Курсы" section will be unlocked right after registration.

ABOUT PHONE VERIFICATION
After registration the app offers to confirm the phone number with a code.
Automatic SMS delivery is not connected yet, so please tap "Подтвердить
позже" — verification is optional and no feature is locked behind it.

TEACHER CABINET (why the app asks for camera and microphone)
Settings → "Кабинет устаза" is a section for teachers only: they publish
video lessons and run live broadcasts from the same app. It requires
credentials issued by the administrator, and the camera is only started
after the teacher taps "Включить камеру". Regular users never see a camera
or microphone prompt. If you would like to inspect it, use:

  login: ⟨ЛОГИН_ДЛЯ_РЕВЬЮ⟩
  password: ⟨ПАРОЛЬ_ДЛЯ_РЕВЬЮ⟩

LIVE BROADCASTS
A broadcast is only on when a teacher starts it, so the "Прямой эфир"
screen will most likely show "Сейчас эфира нет". This is the normal
idle state, not an error.

USER-GENERATED CONTENT
The live chat is the only place where users can post. Messages pass a
profanity filter on the server, every message can be reported (long press),
and its author can be hidden by the reader. Account deletion is available
in "Аккаунт" → "Удалить аккаунт" (visible once signed in).
```

## Чек-лист перед нажатием Submit

- [ ] A-запись домена создана, `enable-https.sh` отработал
- [ ] `ApiConfig.defaultBase` → `https://⟨домен⟩`, `NSAllowsArbitraryLoads` убран
- [ ] `privacy.html` заполнен и открывается по https
- [ ] Номер для ревью зарегистрирован и ему выдан доступ к курсам
- [ ] Учётка устаза для ревью заведена в панели
- [ ] Скриншоты загружены
- [ ] Анкета App Privacy заполнена: телефон, имя, пользовательский контент,
      данные об использовании — всё «связано с личностью», отслеживания нет
- [ ] Возрастной рейтинг: отмечен пользовательский контент
- [ ] Экспортное соответствие: шифрование стандартное (`ITSAppUsesNonExemptEncryption` = false уже в Info.plist)
