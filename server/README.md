# Сервер прямых эфиров «Ирфан»

Схема: устаз стримит по **RTMP** со своего телефона → nginx-rtmp
конвертирует в **HLS** → все приложения смотрят по HTTP. Файл
`status.json` переключается автоматически при старте/окончании эфира —
приложение опрашивает его каждые 15 секунд.

```
Телефон устаза (RTMP) ──▶ nginx-rtmp ──▶ HLS (/var/www/irfan-live/hls)
                              │
                              └─▶ status.json (live: true/false)
                                        ▲
                     Приложения зрителей опрашивают каждые 15 с
```

## Установка на Ubuntu-droplet (159.89.38.67)

```bash
apt update && apt install -y libnginx-mod-rtmp apache2-utils
mkdir -p /var/www/irfan-live/hls /var/www/irfan-api/uploads
cp irfan-live-on.sh irfan-live-off.sh /usr/local/bin/ && chmod +x /usr/local/bin/irfan-live-*.sh
/usr/local/bin/irfan-live-off.sh   # создать начальный status.json
echo '{"updated":"","courses":[]}' > /var/www/irfan-api/courses.json
htpasswd -bc /etc/nginx/.irfan-htpasswd ustaz 'ПАРОЛЬ_УСТАЗА'   # пароль публикации
chown -R www-data:www-data /var/www/irfan-live /var/www/irfan-api
# rtmp-блок (rtmp.conf) добавить в САМЫЙ КОНЕЦ /etc/nginx/nginx.conf (вне http{}),
# location-блоки (http-location.conf) — внутрь server{} сайта.
ufw allow 1935/tcp
nginx -t && systemctl reload nginx
```

## Приложение устаза («Ирфан Устаз»)

- Эфир: вкладка «Эфир» — камера, название, кнопка «Начать эфир»
  (RTMP на `rtmp://159.89.38.67/live`, ключ из настроек).
- Курсы: вкладка «Курсы» — создание/редактирование, загрузка видео,
  кнопка «Опубликовать» кладёт `courses.json` в `/irfan-api/`
  (PUT c basic-auth `ustaz:<пароль>`); студенческое приложение
  читает его в разделе «Курсы».

## Как устазу вести эфир (уже сейчас, до отдельного приложения)

1. Установить бесплатный **Larix Broadcaster** (iOS/Android).
2. Добавить соединение: `rtmp://<сервер>/live/<КЛЮЧ_ПОТОКА>`
   (ключ потока — длинная случайная строка, её знает только устаз;
   задаётся на сервере в `/etc/irfan/stream.key`, см. `irfan-live-on.sh`).
3. Нажать запись — через ~10 секунд эфир появится у всех в приложении.
4. Остановить запись — приложения снова покажут «эфира нет».

Заголовок эфира можно поменять в `/usr/local/bin/irfan-live-on.sh`.

## Проверка

```bash
curl http://159.89.38.67/irfan-live/status.json
```

## Веб-панель администратора

`admin.html` — панель на одном файле, без сборки и внешних библиотек.
Отдаётся тем же `apiserver.py`, поэтому открывается по IP и не упирается
в CORS:

    http://178.104.206.100:8090/admin.html

Вход — учётная запись `admin` из `/etc/irfan/auth.json`. Пароль хранится
только в `sessionStorage` вкладки. Разделы: статистика, ученики с карточками
и выдачей доступа, выданные доступы, коды подтверждения, модерация.

Обновление панели:

    scp server/admin.html root@178.104.206.100:/opt/irfan-server/api/admin.html

**Пока нет HTTPS, пароль идёт по сети открытым текстом** — не заходите из
публичных сетей до `enable-https.sh`.

## Версии файлов

Перед каждой перезаписью через PUT сервер кладёт копию в `api/_versions/`
(последние 5 версий на файл). Ошибочная публикация или одобрение модерации
больше не уносят прежнее содержимое безвозвратно:

    ls /opt/irfan-server/api/_versions/
    cp /opt/irfan-server/api/_versions/news.json.<метка> /opt/irfan-server/api/news.json

## Видео и каталог курсов через админку

В панели два раздела:

- **Видео** — загрузка перетаскиванием или выбором файлов, прогресс,
  **просмотр прямо в панели** (кнопка «▶ Смотреть»), **папки-разделы**,
  поиск, список с размером и датой, отметка «где используется», копирование
  прямой ссылки, удаление. Показывает, сколько на диске свободно.
- **Курсы** — редактор каталога: направления → курсы → уроки. Ссылка урока
  выбирается из уже загруженных файлов или вставляется вручную
  (MP4 или HLS `.m3u8`). Кнопка «Опубликовать студентам» пишет `courses.json`.

Разрешённые типы: `.mp4 .mov .m4v .mp3 .m4a .aac .pdf .jpg .jpeg .png .webp`.
Имена файлов транслитерируются (`Урок 1 — Омовение.mp4` → `Urok-1-Omovenie.mp4`)
и очищаются от небезопасных символов; попытки уйти вверх по дереву сводятся
в `uploads/`.

### Папки

Папки — **разметка**, а не каталоги на диске: файлы как лежали в `uploads/`
плоским списком, так и лежат. Сделано намеренно — иначе перенос урока в
папку менял бы его адрес и ломал уже опубликованные ссылки в `courses.json`
(а уроков на сервере больше двухсот). Поэтому папку можно завести,
переименовать и удалить в любой момент, ничего не сломав: при удалении папки
файлы просто становятся «без папки».

Указатель — `/opt/irfan-server/media-folders.json`, **рядом** с `api/`, а не
внутри: всё, что лежит в `api/`, раздаётся по HTTP, и список файлов стал бы
публичным.

    POST /media/folder  {"op":"create","name":"Таджвид"}     → admin
    POST /media/folder  {"op":"rename","id":"f…","name":"…"}
    POST /media/folder  {"op":"delete","id":"f…"}
    POST /media/move    {"names":["a.mp4"],"folder":"f…"}     — пустая folder = вынуть
    PUT  /uploads/имя.mp4?folder=f…                           — загрузить сразу в папку

`GET /media.json` возвращает `folders` (с числом файлов) и `folder` у каждого
файла. Ответ на `PUT /uploads/…` — JSON с итоговым именем файла: оно меняется
при транслитерации, и панели нужно знать, что именно получилось.

### Отдача видео

Сервер поддерживает `Range` (частичные запросы) — без этого перемотка в
уроке не работала, а iOS-плеер тянул ролик целиком перед стартом. Включён
`HTTP/1.1` с keep-alive: плеер шлёт десятки запросов подряд. На этом же
держится просмотр в панели: плеер берёт файл по **относительной** ссылке
(свой origin) — панель открывают и по https через Tailscale, а страница по
https не имеет права тянуть http-адрес.

Писать через `PUT` можно только в известные файлы и в `uploads/` — список
в `_PUT_ALLOWED`. Раньше админский PUT создавал произвольные файлы внутри
`api/`, включая `.html`, который отдавался бы браузеру с нашего адреса.

## HTTPS для админки без покупки домена — Tailscale Funnel

`enable-tailscale-funnel.sh` даёт стабильную ссылку вида
`https://irfan-server.<хвост>.ts.net/admin.html` с настоящим сертификатом.

Чем это лучше прокси на Railway:

| | Railway-прокси | Tailscale Funnel |
|---|---|---|
| Шифрование до сервера | только до Railway, дальше открытым текстом | сквозное, сертификат на самом сервере |
| Лишнее звено | да | нет |
| Порт 8090 наружу | нужен | **не нужен**, можно закрыть |
| Стабильность ссылки | да | да |

Что нужно от вас: бесплатный аккаунт на tailscale.com, ключ авторизации и
включённый Funnel в политике доступа (в шапке скрипта расписано).

    TS_AUTHKEY=tskey-... bash enable-tailscale-funnel.sh

### ⚠️ Порт 8090 закрывать НЕЛЬЗЯ

На него ходит приложение студентов (`ApiConfig.defaultBase`) и на него же
указывают ссылки HLS в `live-on.sh`. Закрыть его можно будет только когда
приложение переведут на другой адрес.

Funnel даёт защищённый вход **администратору**; прямой адрес остаётся
рабочим для приложения.

**Чего это не делает:** приложение студентов продолжает ходить на IP по HTTP.
Funnel — канал для служебного доступа, а не CDN: гнать через него видео и
эфир нельзя. Персональные данные учеников закроет только домен с сертификатом
на самом сервере (`enable-https.sh`).

### Рабочий адрес админки

    https://irfan-server.tailff3502.ts.net/admin.html

Включено 2026-07-29. Сертификат Let's Encrypt (`CN=irfan-server.tailff3502.ts.net`)
выпущен на сам сервер и обновляется автоматически. `tailscaled` в автозапуске,
конфигурация Funnel переживает перезагрузку.

Управление:

    tailscale funnel status            # проверить
    tailscale funnel --https=443 off   # выключить

### Ссылки на уроки всегда ведут на публичный адрес

Панель открывают и по защищённой ссылке Tailscale, и по прямому IP. Складывать
ссылку урока из адреса администратора нельзя: ученикам достался бы адрес
Funnel — служебного канала, не предназначенного для раздачи видео, да ещё и
в семь раз медленнее.

Поэтому сервер сам сообщает панели публичный адрес (`mediaBase` в
`/media.json`), а панель подставляет его в каталог. Поменять:

    systemctl edit irfan-api      # Environment=IRFAN_MEDIA_BASE=https://…

### Скорость загрузки

| Путь | 40 МБ |
|---|---|
| Прямой IP | ~6 сек (6.7 МБ/с) |
| Через Funnel | ~41 сек (1.0 МБ/с) |

Funnel идёт через relay-инфраструктуру Tailscale — она не для объёмных
передач. Для крупных уроков быстрее заливать по прямому адресу из доверенной
сети; через Funnel удобно для обычных 20–60 МБ.
